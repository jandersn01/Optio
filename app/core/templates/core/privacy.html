{% blocktrans %}Política de Privacidade{% endblocktrans %}

{% trans "Data de entrada em vigor:" %} {% trans "17 de junho de 2026" %}

{% blocktrans %}Bem-vindo ao Optio. A sua privacidade e a segurança dos seus dados pessoais são fundamentais para nós. Esta Política de Privacidade descreve como recolhemos, utilizamos, protegemos e gerimos as suas informações quando utiliza a nossa plataforma de pesquisa de cursos de pós-graduação gratuitos, em estrita conformidade com a Lei Geral de Proteção de Dados (LGPD).{% endblocktrans %}

{% trans "1. Que dados recolhemos?" %}

{% trans "Para garantir o funcionamento pleno da plataforma, recolhemos apenas os dados estritamente necessários:" %}

  • {% blocktrans %}Dados de Registo: Nome completo e endereço de correio eletrónico (fornecidos no momento da criação da conta).{% endblocktrans %}
  • {% blocktrans %}Dados de Utilização e Preferências: O seu histórico de pesquisas, os parâmetros que define (áreas de interesse e modalidades) e os cursos que guarda nos seus favoritos.{% endblocktrans %}
  • {% blocktrans %}Dados de Sessão: Informações técnicas essenciais para manter a sua conta segura, como cookies de sessão e de proteção contra falsificação de pedidos (CSRF).{% endblocktrans %}

{% trans "2. Como utilizamos os seus dados?" %}

{% trans "A finalidade exclusiva do tratamento dos seus dados é a prestação do serviço do Optio:" %}

  • {% blocktrans %}Processamento de Pesquisas: Utilizar os seus parâmetros para orquestrar a recolha de dados públicos sobre cursos nas instituições de ensino.{% endblocktrans %}
  • {% blocktrans %}Notificações: Enviar os resultados das suas pesquisas e alertas de novos cursos diretamente para o seu correio eletrónico.{% endblocktrans %}
  • {% blocktrans %}Personalização: Manter o seu painel de controlo (Dashboard) atualizado com as suas métricas e o seu histórico individual.{% endblocktrans %}

{% trans "3. Tratamento por Inteligência Artificial e Terceiros" %}

{% blocktrans %}O Optio utiliza ferramentas automatizadas e modelos de Inteligência Artificial para processar o texto das páginas web públicas encontradas. A sua identidade, o seu correio eletrónico e os seus dados pessoais nunca são enviados para estes modelos de IA. A IA é utilizada estritamente como uma ferramenta de extração de dados sobre os cursos, garantindo o anonimato da sua pesquisa. Não vendemos nem partilhamos o seu perfil com terceiros.{% endblocktrans %}

{% trans "4. Segurança e Proteção (Security by Design)" %}

{% blocktrans %}Implementamos controlos de segurança rigorosos na nossa arquitetura de software para garantir a proteção das suas informações:{% endblocktrans %}

  • {% blocktrans %}Isolamento de Dados (Tenant Isolation): A nossa infraestrutura assegura que os seus dados de pesquisa e os seus favoritos são estritamente privados e inacessíveis a outros utilizadores.{% endblocktrans %}
  • {% blocktrans %}Criptografia: A sua palavra-passe não é armazenada em texto limpo. Utilizamos algoritmos de hashing (PBKDF2 com SHA256) impossíveis de reverter.{% endblocktrans %}
  • {% blocktrans %}Comunicações Seguras: Todo o tráfego entre o seu navegador e os nossos servidores é forçado a utilizar protocolos seguros (HTTPS com HSTS).{% endblocktrans %}

{% trans "5. Os Seus Direitos (LGPD)" %}

{% trans "O utilizador tem controlo total sobre os seus dados. A qualquer momento, através da plataforma, pode:" %}

  • {% blocktrans %}Aceder e Retificar: Visualizar e alterar as suas preferências de notificação e os seus dados de perfil.{% endblocktrans %}
  • {% blocktrans %}Apagar o Histórico: Eliminar de forma permanente pesquisas específicas ou todo o seu histórico de utilização.{% endblocktrans %}
  • {% blocktrans %}Revogar o Consentimento: Solicitar a eliminação completa da sua conta e de todos os dados associados aos nossos servidores.{% endblocktrans %}

{% trans "6. Alterações a esta Política" %}

{% blocktrans %}Podemos atualizar esta Política de Privacidade periodicamente para refletir melhorias no sistema ou alterações legais. Notificaremos os utilizadores através do correio eletrónico registado sempre que ocorrerem mudanças significativas.{% endblocktrans %}

{% trans "7. Contacto" %}

{% blocktrans %}Se tiver dúvidas sobre esta política ou pretender exercer os seus direitos de privacidade que não estejam disponíveis de forma automatizada no painel, contacte-nos através do endereço: privacidade@optio.com.{% endblocktrans %}
